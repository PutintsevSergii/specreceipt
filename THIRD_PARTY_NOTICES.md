# Third-party notices

The npm archive contains SpecReceipt's generated JavaScript and copied project templates, Skills, Python source and documentation. npm resolves `yaml` and `smol-toml` as separate dependencies; their licenses and notices are supplied with those packages.

OpenSpec, CodeGraph and Graphify are optional external tools provisioned separately, not redistributed in this archive. ADR documents credit the external concepts and projects referenced in the design. Source provenance and the owner's right to license every included project file still require owner confirmation before publication.
