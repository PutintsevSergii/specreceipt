# Security

Please avoid posting secrets or exploit details in a public issue. Until a public repository with private vulnerability reporting is available, send a private report to the repository owner through the contact method listed on their GitHub profile. Include affected version, reproduction steps, impact and a proposed fix if known.

SpecReceipt records local approvals and evidence but does not authenticate their authors. Editable scripts and local state are not a security boundary. The project owner must configure repository permissions, CI protections and agent tool permissions separately.
